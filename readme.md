# Build Guide

> cmake -S . -B build
> cmake --build Build

**Executable**
> ./build/lumine-v1

---

**Movement Keys**

W -> Forward z-axis
S -> Backward z-axis
D -> Left x-axis
A -> Right x-axis
Shift -> Down y-axis
Space -> Up y-axis
Q -> Toggle debug window / enable movement
Escape -> Close application

movement is disable by default to enable it toggle debug window using `Q`
